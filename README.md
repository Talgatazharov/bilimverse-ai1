# BILIMVERSE AI — Web

Browser-first Kazakh Future Fantasy learning platform for grades 1–4.
Built with Flutter Web, Riverpod and go_router; deployed as static files to Sites.

## Run locally

```powershell
flutter pub get
flutter run -d chrome
```

## Verify and build

```powershell
flutter analyze
flutter test
node scripts/build-web.mjs
```

Release output is `dist/`. The renderer resources and fonts are bundled locally.
Hash routes allow static hosting without rewrite rules: `/#/world`,
`/#/kingdom`, `/#/onboarding`, `/#/settings`.

## Working demo

- Browser welcome page with a 2.6-second portal opening and immediate navigation.
- Five-step onboarding: name, grade, avatar, Qyran and first world.
- Desktop world map plus travel journal; responsive single-column phone website.
- Illustrated yurt, mountains, river, seven landmarks, clouds, birds and fog.
- Playable local starter missions for grades 1–4 in mathematics, Kazakh, literature,
  world knowledge, science, English, digital literacy and creativity. Each has
  five questions and a five-step review; grade 3 mathematics has two authored
  missions.
- A local cross-subject story, companion selection, topic-based learning profile,
  and a personal world that opens places as missions are completed.
- Sentence building and robot route tasks use ordered token controls alongside
  choice-based questions.
- Teacher Studio can select a curated local mission, rename it, and assign it
  to the matching grade in the same browser. The Homework page opens assigned
  missions and shows completion.
- First-mission, perfect-result and five-day-streak achievements. Topic attempts,
  streak and companion choice survive reload in the same browser.
- Hints, retry without lost health, 1–3 stars, reward screen and level-up notice.
- First completion grants 200 XP and 15 Тұмар; repeat play improves stars without
  duplicating rewards. Golden Bridge completion draws a bridge on the map.
- Local profile/settings/progress survive browser reload on the same origin.
- Reduced motion follows both browser/system and saved preferences.

`/preview` retains the original design-system harness. Platform files for Android
remain in the repository, but browser delivery is the active product target.

## Honest limits

Demo data lives in this browser, not a synchronized account. The private Sites
link controls access to the website; it is not student login. The expanded
subject content is a local starter set; most non-math questions are reused across
grades and require curriculum review. The story and hints are authored locally,
not generated by an AI model. Real AI, voice recognition, OCR, audio,
real teacher accounts, cross-device assignments, parent mode and complete
curricula are not implemented. Teacher Studio is a same-browser local workflow,
and its mission picker does not generate new questions.
The guardian reviews the mission questions; generated boss questions and the
more elaborate chest/level-up sequence remain future work. No performance claim
is made without profiling on the intended devices.
